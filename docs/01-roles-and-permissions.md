# Роли и права доступа

## Покупатель
### МОЖЕТ:
- Просматривает каталог товаров
- Создает заказ
- Видит только свои заказы
- Может отменить заказ до отправки
- Выбрать способ оплаты (сразу или после доставки)

## НЕ МОЖЕТ:
- Просматривать чужие заказы
- Отменять заказ после на любом другом статусе, кроме собирается
- Создавать, изменять, удалять карточки товаров


## Менеджер
- МОЖЕТ:
- Видит заказы  покупателей и их контактные данные
- Изменяет статусы заказа(собирается, отправлен, доставлен)
- Может отменить заказ с оповещением покупателя на этапе сборки заказа
- Видит товары и их количество на складе
- Видит аналитику продаж

## НЕ МОЖЕТ:
- Создавать, изменять(только статус заказа), удалять заказ клиента
- Изменять карточки товаров и их цену
